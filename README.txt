व्यापार मेला — App Folder
============================

इस folder को GitHub Pages पर upload करें।

मुख्य files:
- index.html              : App shell
- manifest.webmanifest    : Android/PWA install settings
- sw.js                   : Service worker
- icons/icon-192.png      : App icon
- icons/icon-512.png      : App icon

मुख्य Google Apps Script URL पहले से index.html में लगा है।

महत्वपूर्ण:
1. GitHub Pages पर HTTPS के साथ publish करें।
2. Android Chrome में वेबसाइट खोलकर "Install app" / "Add to Home screen" चुनें।
3. iPhone Safari में Share → Add to Home Screen चुनें।
